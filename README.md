## Featured Projects

### [FastAPI RAG Agent](https://github.com/Urvish-10/FastAPI-RAG-Agent)
Production-grade Retrieval-Augmented Generation API with multi-turn conversations and streaming responses. Documents are ingested asynchronously, retrieved from per-user Pinecone namespaces, reranked, and answered by a LangGraph agent with conversation memory persisted in PostgreSQL.  
`FastAPI` `LangGraph` `Pinecone` `Celery` `Redis` `PostgreSQL` `SQLAlchemy` `Docker`

### [Django API Template Kit](https://github.com/Urvish-10/Django-Development-Kit)
Robust DRF starter kit with PostgreSQL, drf-spectacular Swagger integration, and best practices built in.  
`Django` `DRF` `PostgreSQL` `drf-spectacular`
